# 💳 Bank Card UI

A modern and interactive Bank Card / Payment Card UI built with **HTML, CSS and JavaScript**.

This project includes a stylish virtual bank card, card number inputs, automatic focus between inputs, CVV2 input and a responsive design.

---

## ✨ Features

- 💳 Modern Bank Card design
- 🔢 Four separate inputs for card number
- ⚡ Automatic focus to the next input
- 🔐 CVV2 input
- 💜 Neon / Glassmorphism UI
- 🖱️ Interactive hover effects
- 📱 Fully responsive design
- 🔒 Security information section
- 👩‍💻 Personal developer footer
- 🔗 Social & contact links

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Responsive Design
- CSS Gradients
- Glassmorphism
- CSS Animations

---

## 🎯 How It Works

The card number is divided into four separate input fields.

When the user enters **4 digits**, the focus automatically moves to the next field.

After entering the last four digits, the focus automatically moves to the **CVV2** field.

The entered card number is also displayed dynamically on the virtual bank card.
